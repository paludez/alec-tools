# Tool patterns

- A tool with options and a preview has a caddy (see `bbox.ms` + `bboxCaddy.py`, `distribute.ms` + `distributeCaddy.py`): settings struct kept with lib/settings.ms, a session struct, preview with `undo off`, OK redoes it in one `undo "Name" on`, Cancel/Esc/close restores. The `.ms` holds the logic and small functions the caddy calls; the `.py` only builds the panel. A click applies with the last settings, Shift+click or a toolbar right click (`AlecTools_wantsOptions`) opens the caddy. The tool file calls `AlecTools_closeCaddy()` on load and before a new session.
- The Alec Tools toolbar is a Qt `QToolBar` on the Max main window (`tools/AlecToolbar.py`, created by `tools/toolbar.py` at the end of `AlecTools_load`). Each button runs a macro (`macros.run "Alec Tools" name`) with the macro's own text and `iconName:`. The buttons, order, separators and looks are kept in `AlecTools.toolbar.json` in `getDir #userScripts` (defaults in `DEFAULTS`), edited with the Edit Toolbar macro (a right click on the toolbar opens nothing); the dock edge is in the ini. Buttons whose macro reads `AlecTools_wantsOptions()` are listed in `WITH_OPTIONS` (right click = options, corner triangle). Checked buttons and fields refresh on Max's own events (`tools/toolbarEvents.ms`: a NodeEventCallback for selection, transform and geometry, plus units and scene changes) and when the mouse enters the toolbar (Use Center has no event); no timer. Tests: `tests/toolbar_test.ms`.
- A tool that measures in the viewport is a `tool` started with `startTool` (see `measure*.ms`): the first click comes twice, skip `clickno == 2`; right click/Esc ends and clears.
- Status messages go to `displayTempPrompt` / `replacePrompt`, starting with the tool's name, in English like the rest of the UI. Lengths through `units.formatValue`.
- A macro gets an `iconName:` when the user wants one (find it with the Icon Browser macro); shortcut-only macros can go without.
- `audit.md` lists known problems and planned cleanups; strike through an item when it is done, and check it before adding a helper it already plans.
